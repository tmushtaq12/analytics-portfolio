# Dashboard Project

> **Scope:** This folder is a written executive-summary exercise, not an interactive dashboard application. The reproducible static dashboard for the real transaction analysis is generated by the [Retail Transaction Analytics Capstone](../retail-analytics/README.md).

## Overview
This exercise describes how to communicate retail performance to non-technical stakeholders. It does not itself render a dashboard or calculate KPIs.

## Business Goal
Provide a short, clear picture of revenue performance and where the business should focus attention.

## KPIs to Highlight
- total revenue
- monthly sales trend
- revenue by region
- revenue by category
- revenue by customer segment
- sales channel comparison

## Dashboard Questions
- Which measures should an executive see first?
- How can a time trend, market mix, and product mix be shown together?
- What data-quality and margin caveats belong beside the charts?

## Deliverables
- `dashboard_summary.md` — written executive-summary exercise

## Reproducible Dashboard Artifact
The capstone generates a static four-panel chart for monthly recorded positive sales, country mix, product mix, and customer cohort retention. It is not an interactive BI application, and the source does not include product cost or reliable margin fields.

## Business Value
This folder demonstrates dashboard-planning and concise reporting practice. The runnable evidence-backed static dashboard lives in the retail capstone.
