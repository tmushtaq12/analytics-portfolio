- `linear-regression/` — readable scikit-learn modeling and diagnostic analysis
- `sql-analysis/` — business-focused SQL queries

## Reproducibility Standard

Each serious project should include:

1. A real dataset or clearly documented source
2. A readable script that can be run locally
3. Metrics appropriate to the task
4. Generated outputs or error examples
5. A short explanation of limitations and production next steps
